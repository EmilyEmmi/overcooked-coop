# Overcooked 64!

(NOTICE: This mod is a work-in-progress.)

In this mod, you'll make various food items in wacky scenarios. There's no menu right now, so use the /start-level command to play levels. There are 5 levels available right now:
- /start-level 0: Play the test level. This level contains every mechanic, so it's best to leave it for last.
- /start-level 1: Play Level 1. This is a very simple level featuring salad.
- /start-level 2: Play Level 2. This level introduces washing dishes, and also introduces platforming elements.
- /start-level 3: Play Level 3. This level takes place on a ship and introduces soup.
- /start-level 4: Play Level 4. This level contains quicksand with sinking platforms, and introduces burgers.
